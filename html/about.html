Elevator Diagnostics & Control Design Project

Welcome to the about page for Engineering Project VI.

In this project, we are building and controlling an elevator system that leverages a Controller Area Network (CAN) bus communication environment. The system integrates embedded controllers, a Raspberry Pi supervisory controller, and a web-based data repository to allow for remote tracking, diagnostics, and control over the Internet.
